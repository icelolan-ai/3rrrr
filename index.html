How it works

สถาปัตยกรรมของประสบการณ์

True Object Interpolation

ทั้ง 27 คิวเล็ตถูกจับคู่แบบ node-to-node ระหว่างโมเดลปกติและโมเดลระเบิด ตำแหน่งเริ่ม/ปลายถูกอ่านจาก keyframe จริงในไฟล์ GLB แล้ว interpolate ด้วยเวกเตอร์ — ไม่ใช่การสลับโมเดล

Scroll = Timeline

ตำแหน่ง scroll ถูกแปลงเป็นค่า progress 0.0–1.0 แบบ deterministic กลับไปตำแหน่งเดิมได้เป๊ะทุกครั้ง

Gesture-Safe Input

ระบบแยกท่าทางลากแนวนอน (หมุน) ออกจากแนวตั้ง (scroll) บนมือถือ เพื่อไม่ให้ชนกัน

PBR Metallic Lighting

ใช้ physically-based rendering พร้อม environment lighting แบบ procedural เพื่อคงลุคแดงเมทัลลิกมันวาว

Modular & Extensible

แยกเป็น SceneManager, ModelManager, AnimationManager, ScrollController, InteractionController, CameraController, LightingManager, UIManager — พร้อมต่อยอด hotspot, isolate part, label ในอนาคต

Ready for GitHub Pages

โปรเจกต์นี้เป็น static site ล้วน ไม่มี backend ไม่มี Windows path — ดูวิธีติดตั้งแบบละเอียดใน README.md
